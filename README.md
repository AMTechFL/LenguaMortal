# Lengua Mortal

Language-learning as a horror game. 

**Game is still in pre-development. There is no game yet!**

## About

Lengua Mortal is a (soon to be) horror game where you must answer questions correctly in order to unlock doors and advance. The questions will give you a word in a specified language, then you will have to select the correct English word that corresponds to it.

## Current Languages Supported

The game is built for English speakers, with the following languages available:

- Spanish
- Japanese

## Current Development
