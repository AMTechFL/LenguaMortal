# Lengua Mortal

Language-learning as a horror game. 

**Game is still in early development alpha, so everything you see here is subject to change!**

## About

Lengua Mortal is a horror game where you must answer questions correctly in order to unlock doors and advance. The questions will give you a word in a specified language, then you will have to select the correct English word that corresponds to it. You must unlock doors to advance and each door is blocked by a question.

### Controls

- WASD - move
- Shift - sprint
- Left Mouse Click - interact
- Esc - return to menu / exit

### Current Languages Supported

The game is built for English speakers, with the following languages available:

- Spanish
- Japanese

More language support coming soon!

### Current Development

The current version is 0.1.0-alpha, which is the first playable version of Lengua Mortal. Tools used to prepare data were written in Python, with the game itself being developed in Godot (and using GDScript).

More features may be added in the future, although there is no guarantee.
